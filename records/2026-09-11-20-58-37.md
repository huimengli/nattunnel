## 改造

1. **管理页 API 相对化**: `index.html` 中 13 处 `"/api/..."` → `"api/..."`(含 exe 下载 fetch)。
   同一份页面在根部署(http://host/)与子路径部署(https://host/nattunnel-admin/)下均可用。
2. **新增 `server/nginx/nattunnel-embed.conf`**(嵌入现有 vhost, 不新建 server 块):
   - http 上下文: `map $http_upgrade $nattunnel_conn`;
   - `location /tunnel/` → `proxy_pass http://127.0.0.1:8000;`(原样直通: WS 中继 + HTTP 直转短链);
   - `location = /nattunnel-admin` → 301 补尾斜杠(保证相对路径解析);
   - `location /nattunnel-admin/` → `proxy_pass http://127.0.0.1:8000/;`(剥前缀转发管理端+API)。
3. **`config.py`: HOST 默认 0.0.0.0 → 127.0.0.1** — 混部服务器上 FastAPI 不经 TLS 直接暴露公网不安全,
   nginx 反代走回环即可; 本地开发/自测全部经 127.0.0.1, 无影响。
4. **`docs/deploy-keliit-top.md`**: 完整部署步骤(上传保持仓库根布局[exe 下载端点读 `client/dist/`],
   venv+依赖, .env 首启 sqlite+可选 Redis[缺失自动降级内存兜底]+随机管理员密码, systemd 单 worker,
