## 实现

### 1. `database.py`: 支持运行时重建引擎
- `reconfigure(url)` dispose 旧引擎并重绑; `SessionLocal` 改为**稳定代理对象**(各模块 import
  到的名字始终同一实例, 就地热切换); 新增 `get_engine()`。全部现有调用点零改动。

### 2. `seed.py`: 首启环境向导 `_interactive_env_setup()`
- 触发条件(仅交互 tty): `.env` 不存在; 或运行时遇数据库配置类错误(1045/1049/连接拒绝等)重新进入。
- 选项 `[1] MySQL [2] sqlite`:
  - MySQL: 主机[127.0.0.1]/端口[3306]/库名[nattunnel]/账号[nattunnel]/密码(隐藏);
    **立即试连**; 失败且为 1045/1049 时可再输 root 密码 → `_ensure_mysql_schema()` 自动
    `CREATE DATABASE` + `CREATE USER 'user'@127.0.0.1/@localhost` + `GRANT ALL`。
  - sqlite: 路径[./nattunnel.db] 即试即用(免装起步)。
- Redis 连接串(默认 redis://127.0.0.1:6379/0, 可留空降级内存); JWT_SECRET 自动生成(或沿用现有);
  写 `server/.env`(标准模板+注释) → `reconfigure(url)` 热切换 → 继续建表。
- 之后接原有管理员交互创建流程(上轮实现)。
- 非交互(systemd/docker): 行为不变(.env/随机+日志一次性打印); 缺 .env 时日志明确提示手工创建或终端引导。
