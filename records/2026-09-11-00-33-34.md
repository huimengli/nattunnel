### 缺陷与修复(实测发现 4+1 个)

1. `RSAPrivateKey` 无 `public_bytes` → 改 `key.public_key().public_bytes(...)` (seed.py/security.py)。
2. `DatagramTransport.sendto()` 是同步方法, `await` 它抛 TypeError → 去掉 await (client)。
3. selftest 两阶段共享 `client.STOP` 标志未复位 → 抽 `start_client()` 先复位 (selftest)。
4. selftest 清理 `DELETE /api/tunnels/{tid}` 忘带 Bearer → 401 残留孤儿隧道 → 加 token (selftest)。
5. **TCP 竞态(关键)**: 公网侧 T_DATA 可能早于 LAN 客户端建连完成到达而被静默丢弃。
   修复: `run_tcp` 增加 `open_tasks[pid]`, 数据帧到达时先 `await` 建连 task 再入队 (client)。
   表现: EXE E2E 首轮 FAIL(reply=None), 修复后 PASS。

### 环境踩坑(记录供后续会话)

- PyInstaller --onefile = 父+子双进程; `Stop-Process -Id` 只杀父 → 孤儿 exe 互相顶替 LAN 位
  (表现为服务端每秒新 lan 连接+大量登录)。杀 exe 用 `taskkill /F /IM nattunnel-client.exe`。
- sqlite 冒烟路径在并发 WS 风暴下锁竞争会短暂卡死(可自恢复); MySQL 生产不受影响。
