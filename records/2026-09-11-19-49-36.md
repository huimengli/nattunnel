## 本次需求(用户原话)

"不要config.json记录数据,服务器地址在build时用-s --server写死,其他数据都从服务器设置读"

## 实现

### 配置模型重构(无 config.json)
- **删除** `client/config.example.json`; exe/源码运行均不读任何本地配置文件。
- **服务器地址构建时写死**: `build.bat -s <url>`(或 `--server`)生成
  `client/build_config.py`(`SERVER = "..."`),PyInstaller 随包打进 exe;
  缺省回退 `http://127.0.0.1:8000`(本地调试);命令行 `-s` 仅调试可临时覆盖。
- **隧道 ID 只认绑定令牌**: `/api/me` 的 `tunnel_id`;未绑定令牌的令牌直接拒启(提示重新签发)。
- **本地目标主机上移为隧道字段**:
  - `Tunnel.local_target_host`(VARCHAR 255, 默认 127.0.0.1);
  - API: `POST /api/tunnels`、`PATCH /api/tunnels/{tid}`、`GET` 均带该字段;
  - 网页管理端: 隧道表新增"本地目标"列; 新建/编辑弹窗加输入框;
  - `T_CONFIG` 帧载荷新增 `local_target_host`, PATCH 触发热更新(新流生效);
  - 客户端 run_tcp/run_udp 的 live host 从服务器配置初始化并响应热更新。
- **verify_ssl 移除**: https 一律严格校验证书(公网链路必须 TLS)。

### 存量库迁移(无迁移框架的项目约定)
`seed.py` init_db 内幂等 `ALTER TABLE tunnels ADD COLUMN local_target_host ...`,
捕获 duplicate column/MySQL 1060 忽略; 新建库由 create_all 处理。
